Friday Night Funkin' 0.2.4 — Experimental Flash Port

===ESPAÑOL===

He intentado compilar una versión antigua del videojuego Friday Night Funkin' a Adobe Flash

créditos a: https://github.com/FunkinCrew/funkin

He usado como prueba la versión 0.2.4
Luego de solucionar los errores de compilación, el juego se queda en negro después de pasar el logo de HaxeFlixel, también al ejecutar el juego salen errores en el depurador de Adobe Flash Player, he subido el código fuente modificado junto a los archivos swf (tanto el reléase como el debug)

===ENGLISH===

I attempted to compile an older version of the video game *Friday Night Funkin'* for Adobe Flash.

Credits to: https://github.com/FunkinCrew/funkin

I used version 0.2.4 for testing.
After resolving the compilation errors, the screen goes black after the HaxeFlixel logo appears; additionally, errors appear in the Adobe Flash Player debugger when running the game. I have uploaded the modified source code along with the SWF files (both the release and debug versions).
